# reports_unified_v1_3 — Unified Agent Reports

Stores evaluation reports generated by the unified VLA agent (v1.3).

## Purpose

Captures results from validation runs of `vla_unified_agent_v1_3.py` across all supported domains. Includes per-scenario success rates, step counts, adherence scores, and timing data.

## Connection to Main System

- Generated by `run_phase_validation_v1_3.py`
- Uses `vla_unified_agent_v1_3.py` as the core execution engine
- Scenarios typically cover Wikipedia, Google, YouTube, Store, and Booking

## How to Execute

```bash
.venv/bin/python run_phase_validation_v1_3.py
```

## Expected Outputs

| File | Contents |
|------|----------|
| `report_*.md` | Markdown report with results table and metrics |
| `results.json` | Structured JSON with per-scenario details |
| `results.csv` | CSV summary |
