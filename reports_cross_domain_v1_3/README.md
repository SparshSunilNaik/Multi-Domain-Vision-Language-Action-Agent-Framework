# reports_cross_domain_v1_3 — Cross-Domain Evaluation Reports

Stores evaluation reports generated by `cross_domain_eval_v1_3.py`.

## Purpose

Cross-domain evaluation tests the VLA agent's ability to handle diverse web domains (Wikipedia, Google, YouTube, Store, Booking) in a single evaluation run. Reports capture per-domain performance metrics.

## Connection to Main System

- Generated by `cross_domain_eval_v1_3.py`
- Scenarios defined in `cross_domain_scenarios_v1_3.json`
- Uses `vla_unified_agent_v1_3.py` as the execution engine

## How to Execute

```bash
.venv/bin/python cross_domain_eval_v1_3.py
```

## Expected Outputs

| File | Contents |
|------|----------|
| `report_*.md` | Markdown report with per-scenario results table |
| `results.json` | Machine-readable results (success, steps, timing, URLs) |
| `results.csv` | CSV summary for spreadsheet analysis |
