Instructions in, browser actions out.

A web agent that reads every page’s interactive elements, plans with a local LLM, and acts through a real browser. It chains tasks across sites, fills forms from memory, checks risky actions before taking them, and asks a person when it gets stuck.

Ollama qwen3:8b for planning, Playwright for the browser, plain Python in between.

    Every instruction is routed first

    Before any model call, a keyword router picks the engine. Edit words get the authenticated CRUD engine, video words get the composite orchestrator, and everything else goes to the unified agent. A second pass picks the starting site.
